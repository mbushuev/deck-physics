# Deck Physics 0.2.0

## Mafia II Classic

- Added the first Mafia II Classic profile, with GPU APEX clothing, lower CPU overhead from inactive profiling, optimized GPU buffer fills, and faster preparation of render vertices. The profile includes intro skipping and an FPS counter.
- In the built-in benchmark on Steam Deck OLED at 1280 × 800 and APEX PhysX High, stock Steam Proton averaged **13.5 FPS**. The full Deck Physics profile averaged **76.7 FPS** with all effects, the graphics mask, blocking waits, and automatic GPU clocks. Stock used Valve Proton 11.0-3 and Deck Physics used 11.0-2e, so the figures compare complete setups.
- Verified returning to the main menu from gameplay and interrupting the benchmark with GPU Clothing active.

## Installer

- Download and verify the patch set for the selected game directly from the setup window.
- Check Wine compatibility at launch. If Steam updates Wine, Deck Physics can use a compatible Proton installation already on the Deck. Otherwise it starts the game normally.
- Apply supported per-game file replacements through read-only mounts during the game session.

The packaged GPU bridge matches Valve Proton 11.0-2e and requires Steam Linux Runtime 4. The installer and corresponding source archive are separate downloads.
