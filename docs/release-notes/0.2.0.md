# Deck Physics 0.2.0

## Mafia II Classic

- Added a tested Steam profile with intro skipping, an FPS counter, and optional GPU Clothing.
- GPU Clothing preserves accelerated render vertex packing and leaves installed game files intact. Returning to the main menu from gameplay and interrupting the benchmark passed on Steam Deck OLED.
- The built-in benchmark averaged **76.7 FPS** on AC at 1280 × 800, up from **74.4 FPS** with the original packing path, with APEX PhysX High, all effects, the graphics mask, blocking waits, VSync and antialiasing off, and automatic GPU clocks.

## Installer

- Download and verify the patch set for the selected game directly from the setup window.
- Check Wine compatibility at launch. If Steam updates Wine, Deck Physics can use a compatible Proton installation already on the Deck. Otherwise it starts the game normally.
- Apply supported per-game file replacements through read-only mounts during the game session.

The packaged GPU bridge matches Valve Proton 11.0-2e and requires Steam Linux Runtime 4. The installer and corresponding source archive are separate downloads.
