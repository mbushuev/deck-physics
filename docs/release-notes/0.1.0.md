# Deck Physics 0.1.0

Initial release for Steam Deck. Requires Valve Proton 11.0-2e and Steam Linux Runtime 4.

## Game setup

- Configure one game at a time. Setup detects Steam library installations and lets you choose a Windows executable for a Non-Steam shortcut.
- Set intro skipping and the FPS counter per game. Alice also offers Game default, 60 FPS, 90 FPS, and Uncapped.
- Setup verifies the official NVIDIA package and reuses the local copy when available.

## Performance and battery

- The optional Six-CU graphics mask adjusts graphics scheduling.
- The optional Blocking GPU waits patch lets CPU threads sleep while waiting for GPU work.

## Tested on Steam Deck OLED

- Batman: Arkham Asylum GOTY from the Steam library.
- Alice: Madness Returns from the Steam library and a Non-Steam shortcut.

Download the installer archive for setup. The corresponding source archive is available separately.
