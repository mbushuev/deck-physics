# Deck Physics 0.1.0

Initial release for Steam Deck. Setup requires Valve Proton 11.0-2e and Steam Linux Runtime 4.

- Configure each game from a searchable list. Setup detects Steam library installations and lets you choose a Windows executable for a Non-Steam shortcut.
- Choose intro skipping, an FPS counter, and optional performance patches per game. Alice offers the game default, 60 FPS, 90 FPS, and Uncapped.
- The installer includes optional graphics scheduling and blocking GPU waits patches. Setup verifies and reuses the official NVIDIA package on the Deck.

The [compatibility list](../compatibility/README.md) records the tested launch paths and performance references. Follow the [installation guide](../installation.md) to get started.

Download the installer archive for setup. The corresponding source archive is available separately.
