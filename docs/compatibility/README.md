# Tested compatibility

| Game profile | Steam App ID | Startup validation on Steam Deck OLED |
| --- | --- | --- |
| [Batman: Arkham Asylum GOTY](batman-arkham-asylum-goty.md) | 35140 | Passed |
| [Alice: Madness Returns](alice-madness-returns.md) | 19680 | Passed |

Startup validation used SteamOS 3.9.5 in Desktop Mode with Valve Proton 11.0-2e and Steam Linux Runtime 4. Both games reached the title screen with intro skipping and the FPS counter enabled, then again with both settings disabled. The per-game pages record gameplay performance from development builds separately.

The installer configures the profiles listed here. Other titles may work with the upstream compatibility stack. They are outside the current validation coverage. More profiles will be added as games are tested and tuned on Deck.

See the [installation guide](../installation.md) for setup requirements.
