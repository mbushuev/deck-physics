# Changelog

## [0.2.0](docs/release-notes/0.2.0.md)

- Check Wine compatibility at launch and keep games playable with Steam's selected tool after a Proton update.
- Add a Mafia II Classic profile with intro skipping, the FPS counter, and optional GPU Clothing. GPU Clothing keeps the accelerated render packing active and supports returning to the main menu.
- Support read-only per-game file replacements that check the installed game version at setup and launch.
- Download and verify patch sets for the selected game from the Deck Physics patch catalog.

## [0.1.0](docs/release-notes/0.1.0.md)

First release with per-game setup, Steam library detection, a manual executable picker, Alice frame rate presets, and optional performance and battery patches.
